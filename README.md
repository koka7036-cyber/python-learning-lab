# Учебная лаборатория Python

Практический учебный репозиторий: короткие уроки, задания, калькулятор и автоматические тесты. Код предназначен для обучения и не связан с рабочими ботами или секретами.

## Что внутри

- `lessons/` — основы Python: переменные, условия, циклы, функции, списки и словари.
- `projects/calculator.py` — небольшой калькулятор с проверкой ввода.
- `tests/` — тесты на стандартном модуле `unittest`.
- `.github/workflows/tests.yml` — автоматический запуск тестов на GitHub при push и pull request.

## Как запустить на Windows 11

1. Установи Python 3.11 или новее с официального сайта Python. При установке включи добавление Python в PATH.
2. Открой PowerShell в папке репозитория.
3. Запусти калькулятор:

   ```powershell
   py -3 projects/calculator.py
   ```

4. Запусти тесты:

   ```powershell
   py -3 -m unittest discover -s tests -v
   ```

Для уроков сторонние библиотеки не нужны. Файл `requirements.txt` оставлен для будущих учебных зависимостей.

## Как заниматься

1. Открой урок по порядку в папке `lessons/`.
2. Прочитай комментарии и запусти файл командой `py -3 lessons/имя_файла.py`.
3. Измени пример или выполни задание в конце урока.
4. Запускай тесты после изменений.
